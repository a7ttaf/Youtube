Three open-source variable fonts used by `ums-smart-revenue-command-center-soft-dark.html`.
All three are licensed under the **SIL Open Font License, Version 1.1 (OFL-1.1)**.

| `Newsreader-VF.woff2` | Newsreader (variable: opsz, wght) | github.com/productiontype/Newsreader | (c) 2020 The Newsreader Project Authors |

Full license text for each font is preserved in this folder as `LICENSE-MonaSans.txt`,
`LICENSE-Monaspace.txt`, and `LICENSE-Newsreader.txt`. Each file includes the SIL OFL 1.1
license body verbatim alongside the original copyright statement.

## OFL-1.1 summary (not a substitute for the license text)

- Free to use, study, modify, and redistribute, including in commercial products.
- The Reserved Font Names ("Mona Sans", "Monaspace", and their subfamily names) may not be
  used by derivative font files.
- The fonts cannot be sold by themselves; bundling them inside a larger product is allowed.
- Modifications must remain under OFL-1.1.

This folder is parallel to `mockups/FontsPP/`, which carries the proprietary Anthropic/Adobe
fonts used by the canonical mockup. The Soft dark mockup deliberately uses an OFL-only stack
to remain redistributable without additional licensing.
